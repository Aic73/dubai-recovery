# CRYSTAL RECOVERY SERVICE - WEBSITE MAINTENANCE SCHEDULE

## 🔧 DAILY (30 seconds)
1. Open: https://www.crystalrecoveryservice.com/
2. Verify website loads
3. Check phone number is visible: +971 56 344 6682

## 📊 WEEKLY (2 minutes)
1. Run: .\monitor-dashboard.ps1
2. Check Google Search Console for errors
3. Check for any customer feedback about website

## 📈 MONTHLY (5 minutes)
1. Check Google Search Console Performance report
2. Check Bing Webmaster Tools
3. Update sitemap if you add new services
4. Backup your docs/ folder

## 🚀 WHEN ADDING NEW SERVICES
1. Update docs/index.html with new service
2. Update docs/sitemap.xml with new page
3. Run: git add docs/index.html docs/sitemap.xml
4. Run: git commit -m "ADD: New service - [Service Name]"
5. Run: git push
6. Wait 2 minutes for GitHub Pages to update

## 🆘 TROUBLESHOOTING GUIDE

### Website not loading?
1. Check: https://www.githubstatus.com/
2. Use backup: https://aic73.github.io/crystal-recovery-service/
3. Run: .\monitor-dashboard.ps1

### Phone number wrong?
1. Edit: docs/index.html
2. Search for: "+971 56 344 6682"
3. Update to correct number
4. Commit and push changes

### Need to update email?
1. Edit: docs/index.html
2. Search for: "info@crystalrecoveryservice.com"
3. Update to new email
4. Commit and push changes

### Want to add more pages?
1. Create new HTML file in docs/ folder
2. Add link to it in docs/index.html
3. Add URL to docs/sitemap.xml
4. Commit and push changes
